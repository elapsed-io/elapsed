# Icons

The settings and account icons are from **Tabler Icons** (outline set), MIT license
(`LICENSE-tabler-icons.txt`, copied from `tabler/tabler-icons` tag v3.51.0, commit
`58f60538fe2fab2e1459a09198f9bd3b033bf90e`).

`icons.ts` holds their geometry as drawn in the design canvas: the `settings` and `user` outline
icons, at the plan's 1.6 stroke. The geometry matches v3.51.0's `icons/outline/settings.svg` and
`icons/outline/user.svg`; the canvas draws the inner circles with `<circle>` and closes the gear
outline, as earlier Tabler releases did. No Tabler package is installed.
